API examples:

A large listing of free APIs can be found at: https://free-apis.github.io/#/

Some specific examples (that do not require an API key):

Horoscope
https://api-ninjas.com/api/horoscope
Example: https://api.api-ninjas.com/v1/horoscope?zodiac=virgo

TV shows
https://www.tvmaze.com/api
Example: https://api.tvmaze.com/shows/1

Pokemon
https://pokeapi.co/
Example: https://pokeapi.co/api/v2/pokemon/ditto
